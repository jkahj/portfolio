Drawing Translator

Solo project · Full-stack + deployment
Try Live Demo →

A tool for translating engineering drawings that pairs a Gemini LLM for context-aware technical translation with OpenCV template matching for fast, zero-cost symbol detection, then writes the result back onto the drawing without flattening its vector layout.

Tech Used

PythonFlaskOCROpenCV Google Gemini APIDockerGoogle Cloud Run

Key Features

  • Vector-fidelity processing: high-resolution PDF handling that preserves the text layer and vector layout instead of rasterizing the page
  • AI and CV dual-engine pipeline: Gemini for context-aware technical translation, OpenCV template matching for fast, zero-cost auto-detection of symbols and stamps across multi-page drawings
  • Interactive "edit-only" workflow: precise coordinate masking, automated multi-page stamp detection with human review, and logo and background-color blending
  • Automated unit conversion: real-time inch-to-metric conversion for drawing dimensions
  • Containerized with Docker and deployed serverless on Google Cloud Run (asia-east1)

LinkedIn Content Automation

Solo build · Workflow orchestration

A four-workflow n8n system that turns a firehose of engineering news into a steady LinkedIn presence, without letting an LLM publish anything unreviewed. It runs on a schedule in production and has been live since July 2026.

Tech Used

n8nGemini 2.5 FlashLangChainJavaScriptGoogle Sheets APIGmail APIGoogle Drive APILinkedIn APIRSS

How It Works

  • Curator runs every two days at 10:00 Taipei, pulling five feeds: Hacker News (200+ points), TechCrunch AI, a Google News query, Simon Willison, and Pragmatic Engineer
  • Approve By Email watches Gmail for a reply carrying an image and a token, uploads the image to Drive, and flips the row to approved
  • Publisher posts one approved draft to LinkedIn every Tuesday and Thursday at 09:00, then marks it posted
  • Failure Alert fires on any error, emailing the workflow name, failing node, message, and a link to the execution

Engineering Notes

  • Deduplication runs across executions, keyed on article URL, so a story is never drafted twice
  • Relevance filtering combines a keyword allowlist with a 168 hour recency cutoff, capped at two candidates per run
  • Article scraping strips scripts, nav, and footers, decodes entities, caps at 6,000 characters, and falls back to the RSS snippet when extraction yields too little
  • Every feed and fetch retries with backoff and degrades gracefully, so one dead source cannot break a run
  • The drafting prompt bans unsupported claims, invented personal experience, and a list of filler words, keeping output grounded in the source article
  • Google Sheets acts as the state machine: pending, approved, posted

Japanese Deep Learning

Solo build · Vanilla JavaScript PWA · In development
Try Live Demo →

An offline-first PWA for JLPT N5 to N1 study, built solo with no framework and no build step. Around 19,000 lines of vanilla JavaScript in a single document, which keeps the whole app to one cacheable file.

Tech Used

JavaScriptPWAService Worker Firebase AuthFirestoreCanvas API GitHub Actions

Key Features

  • Spaced-repetition engine: srsLevel 0 to 5 with scheduled review dates, moving words through new, learning, review, and mastered
  • Four quiz modes (reading, listening, cloze, grammar cloze) plus a retry mode that replays only missed items
  • 19,002-word JMdict dictionary with conjugation tables, pitch accents, kanji breakdowns, and collocations
  • 147 grammar points with structure, explanation, and examples
  • Offline-first sync: localStorage as read cache, optimistic writes, debounced flush to Firestore
  • Google sign-in with Firestore rules scoping each user to their own subtree
  • Traditional Chinese definitions pre-baked at build time rather than translated at runtime, trading 951 KB for instant lookups
  • Canvas-animated themes: koi pond in light mode, lantern night lake in dark
  • Auto-deployed to Firebase Hosting via GitHub Actions on every push to main
